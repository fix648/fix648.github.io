N337 — Secure Encrypted Notes Backup

প্রথমে Personal Portal-এ Login করুন। এই পেজ শুধু Database থেকে তথ্য পড়বে; কোনো তথ্য পরিবর্তন করবে না।

Backup-এ চারটি user-scoped Table থাকবে: Notes, Notebooks, note_locks, notebook_locks। অন্য Table ও Auth/Storage/Database Functions থাকবে না। এটি পূর্ণ PostgreSQL Database Backup নয়।

এই Password হারালে Backup খুলতে পারবেন না। এখানে বা Screenshot-এ Password দেখাবেন না।

Ready

এখনও Backup তৈরি হয়নি।

ফাইল ডাউনলোড হলে Google Drive → Personal_Portal → Backup-এ নিজে Upload করুন। Upload হওয়ার আগে Supabase-এর কোনো ডাটা মুছবেন না।
